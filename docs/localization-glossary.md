## Правила

1. Один язык на экране: интерфейс никогда не показывает два перевода сразу.
2. Ключи в `src/messages/ru.json` и `src/messages/kk.json` (а также в
   `src/content/fire-school/*.json`) обязаны совпадать —
   проверяется `npm run check:locales`.
3. Новые термины добавляются сюда до того, как попадут в locale-файлы.
4. Названия брендов и продукта (SAQ) не переводятся.
